Herstellungsprozess

Dokumentation meines Projekts "Foggy Fights"

1. Die Planung

Ich wollte eine Website für ein Game erstellen. Mein Ziel war ein düsteres Design (Dark Mode). Zuerst habe ich das Layout auf Papier skizziert.

2. Programmierung (HTML)

Ich habe das Skelett der Seite mit HTML5 gebaut. Dabei habe ich Header, Main und Footer Bereiche genutzt.

3. Design (CSS)

Mit CSS3 habe ich die Farben angepasst. Wichtig war das Responsive Design, damit die Seite auf dem Smartphone funktioniert.

4. Hosting

Die Seite wurde via GitHub Pages veröffentlicht. Das ermöglicht eine weltweite Erreichbarkeit über einen QR-Code.
