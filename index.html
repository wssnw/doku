Herstellungsprozess: Foggy Fights

Die Vision

Ziel war es, eine düstere, atmosphärische Web-Umgebung zu schaffen, die den User sofort in die Welt von "Foggy Fights" zieht. Das Design nutzt gezielte Lichteffekte (Glow) auf dunklem Grund.

Technische Umsetzung

Die Seite basiert auf einem Mobile-First Ansatz, funktioniert aber dank CSS Flexbox und Clamp-Funktionen auch perfekt auf Ultra-Wide Monitoren. Das Bild im Hintergrund wird dynamisch skaliert.
